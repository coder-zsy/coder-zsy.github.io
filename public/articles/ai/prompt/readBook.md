## 2. 逐章深度分析（详细 Markdown 笔记）

- **层级约定**：严格按目录来——用 **H2（##）** 表示篇章，用 **H3（###）** 表示具体章节。
- **篇章级内在逻辑**：每个**篇章**（Part）下、在具体章节之前，须用 **3 ～ 5 句话**概括 **本篇内在逻辑**：该部分在全书中的角色、论证如何层层推进、各章如何衔接（因果 / 递进 / 并列）；突出「这一块在讲什么逻辑」即可，不必逐章罗列标题。引言、结语若独立成节，可不单独写篇章逻辑。
- **每章须做内在逻辑分析**：各章分析应呈现**论证线索与概念关联**，而不是论点与论据的简单罗列。每章必须包含以下模块，且写作时按「逻辑如何展开」组织：

| 模块 | 说明 |
| --- | --- |
| **论证线索** | 本章论证如何展开（如 现象 → 机制 → 推论），概念/论点之间的因果、递进、对比关系，以及本章在所属篇章中的位置。**与「核心议题」区分**：论证线索侧重「如何展开、与前后章衔接」，核心议题侧重「本章要回答的问题或核心结论」，避免同一句话在两处重复。 |
| **核心议题** | 用一句话精准概括本章核心问题或主要论点。 |
| **关键概念** | 本章涉及的核心概念须在本章内给出清晰的定义或简短段落说明（格式示例：**概念名**：定义或 1 ～ 2 句解释），避免只提术语不解释；可集中写在此处，或在首次出现该概念的段落中括号补充。 |
| **关键证据/案例** | 按**论证逻辑**组织：显式对应论证线索中的步骤（如「第一步 现象 → 证据 A；第二步 机制 → 证据 B」），写出作者用哪些实验/案例/数据支撑哪一步推理；书中经典实验/案例若有则融合在此处（每章 1 ～ 3 个，写出实验/情境、结果与对应概念）。避免平铺罗列、与论证脱节。 |
| **底层思维模型** | 本章背后的思维模型、心理学或跨学科原理；**须至少一处**点明与本书其他概念或章节的关联（如「与 X 章 X 概念的关系」），便于形成全书概念网络。 |
| **复盘思考** | 针对该章提出一个值得深思的问题或可应用场景；**须与本章论证线索或核心概念直接挂钩**，避免泛泛而谈。 |

- **引言、结语**：与正文章节同样按上述模块拆解；结语可强调「与全书的收束关系」。
- **附录、后附**：可简要概括或并入相关篇章，不必每节都写满四模块。
- **篇幅与平衡**：若某章经典实验/案例多，关键证据/案例可适当展开；若某章偏概念整合，可精简证据、强化与前后章的衔接。论证线索与关键证据/案例的对应要清晰，避免堆砌。
