# 《思考的快与慢》读书笔记 · PPT 文字稿

> 核心问题：人如何做判断与选择？为何总是系统性偏离理性？

---

## 第一部分：双系统——底层机制

### 幻灯片 1：双系统概览（系统 1 vs 系统 2）

- 多数时候由**系统 1**主导；**系统 2**在需要时介入

| 维度 | 系统 1（快思考） | 系统 2（慢思考） |
| --- | --- | --- |
| 分工 | 自动加工、直觉与启发式 | 复杂任务、有意识推理与自控 |
| 速度 | 自动、快速 | 慢速、费力 |
| 注意力 | 无需意志努力 | 需要注意力 |
| 思维 | 联想式 | 逻辑式 |
| 控制 | 难以控制 | 可控制 |
| 例子 | 看到愤怒的脸立即产生情绪；饥饿与疲劳时更易发火或冲动决定 | 做 17×24 运算时瞳孔扩张；延迟满足 |

### 幻灯片 2：双系统的协作与冲突

1. **系统 1 自动执行**，在注意力之外“填空”，制造“看见全部”的错觉
2. **系统 2 启动时会抑制**系统 1 的自动反应
3. **系统 2 有惰性**：资源耗尽时不愿启动，费力加工
4. **自我损耗**：认知与情绪自控共用有限资源；资源耗尽时，直觉与冲动占上风，更易维持现状与否定

## 第二部分：系统 1 如何工作

### 幻灯片 3：决策公式

**决策 = 情境依赖（联想 → 启动 → 流畅性启发 → 常态理论）**

### 幻灯片 4：联想与启动

- **联想记忆网络**：一个概念被激活后，会扩散到相关节点
- **启动**：自动、无意识，却会系统性改变判断
- **无关线索也可影响判断**：如「香蕉–呕吐」的联想；语法混乱的一句话仍不影响阅读（系统 1 自动补全）
- **具身认知**：身体状态通过联想影响情绪与判断  
  例：用嘴含住铅笔做出微笑动作，会觉得漫画更好笑；噘嘴则相反

### 幻灯片 5：流畅性启发

**案例**：科学家究研明表：汉字的序顺并不影阅响读，比如当你完看这段话的时，才候发觉这几句全话是乱的。

- 加工越容易 → 越容易被误判为“可能”“正确”“真实”
- 系统 1 不区分“容易想到”和“真的更可能”
- **应用**：股票代码好读的公司被误以为回报更高；想象和回忆的事件被认为更可能发生；能激发联想的环境更易产生创新
- 通过流畅性会**增加主观真实感、强化信心**

### 幻灯片 6：常态理论与情境依赖

- **常态理论**：不断构建和更新“正常”的参照；把意外事后合理化 → “后见之明”“眼见为实”；容易忽略统计与基准信息
- **情境依赖的知觉**：同一刺激在不同情境下被赋予不同含义（如字母 B vs 数字 13）；系统 1 追求连贯性，会自动“填满”语境
- **信念偏好**：常被首因、光环效应等绑架

### 幻灯片 7：启发式——系统 1 的省力策略

- **替代**：复杂问题被替换成简单问题，答案直接当原题答案  
  例：“谁更可能当选？”→“这人看起来像赢家吗？”
- **代表性**：像不像某类；忽视基础比率，违背贝叶斯
- **可得性**：想不想得到；近期新闻、身边案例会高估风险
- **锚定**：先出现的数字或信息成为锚，后续估计围绕锚且调整不足；问卷中的默认值都是锚
- **情感启发式**：因为喜欢所以认同；喜不喜欢代替对不对

### 幻灯片 8：系统 1 的典型偏见

- **情绪与风险**：对“可怕但罕见”的事件过度反应，忽视更大概率风险
- **合取谬误**：更具体、更“像某类”的描述被认为更可能（联言 ≤ 单言）
- **因果比统计更有说服力**：有因果故事的基础比率才更被采纳
- **回归均值**：把回归当因果是常见偏误；回归是统计必然，非干预结果
- **直觉预测**：常过于极端、过度自信，对极端情况过度反应

## 第三部分：过度自信与决策失误

### 幻灯片 9：知道的错觉

- 后见之明 → 高估事前的可预测性
- 记忆被事后信息污染，重构“当时就知道”的叙事
- 记忆与叙事会改写“当时就知道”的错觉

### 幻灯片 10：何时相信专家直觉？

- **未来在多数领域不可预测**：只有规律稳定、反馈及时的环境才适合发展专家直觉
- **适合**：高规律性、充足反馈、长期训练——如棋手、消防员
- **慎用**：医生诊断、投资选股等噪声大、反馈滞后——专家预测常不优于随机或简单规则
- **结论**：专家难以稳定地给线索赋权；**少量关键变量构建的线性模型**往往稳定优于专家综合判断

### 幻灯片 11：规划谬误与外部意见

- **内部意见**：基于当前案例的细节与故事（我们天然偏向）
- **外部意见**：同类案例的统计分布（常被忽略）
- 规划谬误普遍存在：项目时长、成本、难度常被低估

### 幻灯片 12：乐观的双面

- **好处**：推动行动与创新
- **代价**：过度自信、规划谬误、竞争忽视（如大片扎堆）

## 第四部分：决策模型——风险与选择

### 幻灯片 13：从期望效用到前景理论

- **期望效用**（传统）：理性人、线性效用、线性概率权重
- **前景理论**（卡尼曼与特沃斯基）：描述人“实际如何选择”
  - **价值函数**：以参照点为原点；损失痛苦 ≈ 等额收益快乐的两倍（损失厌恶）；两端边际敏感度递减
  - **概率权重**：非线性；小概率被高估（可能性效应），接近 100% 被特别看重（确定性效应）

### 幻灯片 14：损失厌恶与反射效应

- **损失厌恶**：损失带来的痛苦约是等额收益快乐的两倍
- **反射效应**：收益区风险规避，损失区风险寻求；偏好随参照点“反射”翻转

### 幻灯片 15：四重模式（收益/损失 × 概率高/低）

|          | 高概率                   | 低概率               |
| -------- | ------------------------ | -------------------- |
| **收益** | 风险规避（宁要确定收益） | 风险寻求（如买彩票） |
| **损失** | 风险寻求（宁肯赌一把）   | 风险规避（如买保险） |

### 幻灯片 16：禀赋效应与心理账户

- **禀赋效应**：拥有即提高主观价值；卖价高于买价；与损失厌恶结合 → 现状偏见
- **心理账户**：不同账户不同参照点与风险态度；可解释“卖盈持亏”等行为

### 幻灯片 17：框架与参照点

- **公平作参照点**：人们用“公平”作为交易与分配的参照点；对偏离“公平”（如提价、降薪）的厌恶会触发强烈反应，甚至放弃互利
- **参照点的来源**：目标（原价/原薪）、现状（心理预期）、社会比较（别人/别处）——实际低于参照点易被判为“不公平”
- **政策考量**：在不违背效率的前提下，如何减少“公平感”的冲击
- **窄/宽框架**：窄框架放大损失厌恶（如频繁看涨跌）；宽框架平滑波动、更接近理性（如定投、分散、长期视角）
- **评估模式**：综合评估 vs 单独评估会引发**偏好逆转**（综合时更关注可比较维度，单独时更关注情感与故事）

### 幻灯片 18：罕见事件与风险

- 罕见事件被**可能性 + 可得性**双重扭曲：报道多、画面冲击、身边案例 → 主观上高估（小概率+高可得性 → 觉得很常见/很可怕）
- **长序列中的分母忽视**：在长期中某些罕见事件又容易被忽视
- 没故事、统计上更致命的慢性风险因不易被想起而容易被低估

## 第五部分：纠偏——如何更理性

### 幻灯片 19：统计思维与基准

- 大数法则：大样本才稳定，小样本波动大
- 人们对小样本赋予因果、编故事，高估规律性
- 用基准与回归约束提高校准度，避免极端预测

### 幻灯片 20：针对判断偏误的纠偏

- **流畅性**：用“反流畅”检验——换表述、问相反问题、逆向思维
- **情境/叙事**：主动引入统计来对冲叙事效应；真实决策应基于事前信息与概率
- **锚定**：警惕被他人设锚；可主动设定锚（如谈判中的先出价）
- **合取谬误**：去掉细节后检验概率是否应更高
- **情绪与风险**：决策时兼顾统计与情绪两种结果的影响

### 幻灯片 21：针对选择与风险的纠偏

- **禀赋效应**：用机会成本思考（而非沉没成本）、习惯“交换”思维
- **框架与罕见事件**：宽框架、长期视角（如定投、分散）；用统计规律对冲情绪
- **换框架检验**：同一决策用收益/损失、单独/综合、宽/窄框架各表述一遍，看偏好是否稳定

### 幻灯片 22：流程与制度纠偏

- **公式化预测**：多数情况下优于非结构化专家判断
- **事前记录**：减少后见之明
- **事前验尸**：假设项目已失败，反推原因，暴露风险（如新项目必须列出至少三个失败原因）
- **外部意见**：主动采纳同类案例的统计分布，减少过度乐观与规划谬误
- **流程设计**：通过强制外部意见、事前验尸等流程对冲本能偏差
- **冷静期**：重要决策前强制让系统 2 参与，减少冲动与锚定

## 第六部分：幸福——两个自我

### 幻灯片 23：体验自我与记忆自我

- **体验自我**：活在当下
- **记忆自我**：负责叙事与决策
- 决策时预期的效用（决策效用）与事后实际体验（体验效用）常不一致；记忆与叙事会改写体验

### 幻灯片 24：幸福与评价

- 评价受**峰终定律**与**时长忽视**主导
- 幸福的双重含义：体验正面的情绪 vs 生活满意度的评价
- 生活满意度易受当前情境与可得信息影响；**放大的幸福错觉**提醒我们：我们对自身的判断并不透明
