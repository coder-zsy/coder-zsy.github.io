# 《万师傅 AI 研发白皮书》目录说明

本目录用于按章节拆分白皮书内容，采用“先蓝图、后逐章”的输出方式。

## 当前状态

- 已完成：`00_蓝图包.md`（供审核）
- 未开始：正文章节（待蓝图包审核后逐章产出）

## 目录结构

- `00_蓝图包.md`：目录到三级、Top10 场景、样章设计、安全基线、试点度量
- `01_通用能力/`：AI 基础能力、提示工程、上下文管理、安全与评审
- `02_岗位场景/`：研发/产品/设计/测试/运维岗位实践
- `03_SDLC全流程/`：需求到发布运维的端到端实践
- `04_附录工具箱/`：速查表、检查清单、模板库、反例库

## 产出原则

1. 每章固定结构：场景、目标、输入、步骤、输出、验收、误区、工具。
2. 所有建议优先落到“可执行模板”与“可验证清单”。
3. 先满足内部 MVP，再评估对外脱敏版。
